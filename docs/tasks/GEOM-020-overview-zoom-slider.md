# GEOM-020 空间总览缩放条

状态：模拟验证通过，待真实业务验收
更新日期：2026-11-18
基线/交付版本：feature/overview-canvas-controls（基于 origin/main 937f7cf，功能代码 ad8b527）

## 目标与验收

2026-11-17 初版在画布底部新增 WPS 风格缩放控件；2026-11-18 按用户确认，将完整缩放条移到顶部工具栏右侧原缩放区域，移除旧顶部缩小、百分比和放大按钮。“适屏”保留在缩放条右侧，画布底部只保留“按住对照原图”等原操作按钮，页面只有一套缩放滑块。

控件依次显示当前百分比、减号、可拖动滑块和加号；加减按钮与滚轮共用相机状态，滑块可直接设定视图比例。100% 表示当前适屏比例，滑块范围为 10%–500%，步进 5%。

缩放以画布中心为锚点，只改变相机，不改变空间几何、毫米尺寸或选中空间。顶部工具栏在空间不足时换行，缩放条和“适屏”不再因窄屏直接隐藏。

每次进入空间总览后，第一次拖动滑块时显示“可以通过 ALT + 滚轮进行调整”，约 2.6 秒后自动消失；同一组件实例内后续拖动不重复显示，组件卸载时清理计时器。初版提示位于底部控件上方，移至顶部后改为在控件下方显示，避免向上越界。

## 实现文件

- `frontend/app/components/OfficeCanvas/SpaceReview.vue`：维护唯一缩放控件、百分比、首次提示状态和 `onZoomSlider`，复用现有 `zoom`；最新模板将控件放在 `.review-toolbar .review-zoom` 内。
- `frontend/app/assets/css/space-review.css`：维护顶部控件布局、滑块与向下提示框样式、工具栏和窄屏换行。
- `frontend/scripts/e2e-overview-canvas-controls.mjs`：覆盖唯一控件、顶部位置、适屏与底部按钮保留、加减、滑块、首次提示和几何不变性。
